## Install ComfyUI

```bash title="install.sh"
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI
python3 -m venv .venv && source .venv/bin/activate
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu130
pip install -r requirements.txt "huggingface_hub[cli]"
```

## Generate

Workflow → Browse Templates → Image. There are three official templates:

- **Qwen Image 2.1: Text to Image** — start here.
- **Qwen Image 2.1: Image Edit** — change a photo using two reference images.
- **Remove Background: Qwen Image 2.1** — cut-outs with real transparency.

The templates ship with the INT8 files. Set **Load Diffusion Model** to `qwen_image_2.1_bf16`, and on the PRO 6000 set **Load CLIP** to `qwen3vl_8b_bf16`.

Defaults are 25 steps, CFG 1, euler / simple. To get native 2K, set *Resolution Selector* to 4.0 MP (2048 × 2048).

**Editing:** name each image by its tag, `<image1>` then `<image2>`, in the order they're connected. The output takes the first image's aspect ratio.

```text title="prompt"
Keep the person in <image1> exactly — face, pose, lighting.
Replace the shirt with the denim shirt from <image2>.
Leave the background untouched.
```

<Tip>
Qwen-Image is at its best with text, so quote the exact words you want on the image: a poster headline, a label, a UI string. For a sticker or logo, ask for a transparent background and keep the PNG.
</Tip>
