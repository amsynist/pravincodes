MiniMax H3 generates video **with native stereo audio** from text, keyframes or references. Here's the shortest path to running it in ComfyUI on one card.

<Specs items={[
  ["Generator", "33B · FL2VA (text/frames) + Ref2VA (references)"],
  ["Text encoder", "Qwen3-VL-32B"],
  ["Output", "4–15 s · 24 fps · stereo"],
  ["Native size", "1344 × 768"],
]} />

## Pick your GPU

Choose once — every block below follows your pick.

<Tabs group="gpu" labels={["RTX 5090 · 32 GB", "RTX PRO 6000 · 96 GB"]}>
<Tab>

**Pruned INT8** — ComfyUI's default build. The generator and encoder don't fit in 32 GB together, so ComfyUI loads them in turn.

| File | Size |
| --- | --- |
| Generator · pruned INT8 | 21.0 GB |
| Text encoder · NVFP4 | 15.7 GB |

</Tab>
<Tab>

**The full model — unpruned BF16.** 96 GB holds it with the encoder, and everything stays loaded between runs.

| File | Size |
| --- | --- |
| Generator · full BF16 | 66.3 GB |
| Text encoder · NVFP4 | 15.7 GB |

Want more headroom? Swap in the unpruned INT8 generator (34.0 GB).

</Tab>
</Tabs>

<Note>
Both cards are Blackwell, which the NVFP4 encoder needs — and it only runs at full speed on the CUDA 13 (`cu130`) PyTorch installed below. All files are from <a href="https://huggingface.co/Comfy-Org/MiniMax-H3">Comfy-Org/MiniMax-H3</a>.
</Note>

## Install ComfyUI

```bash title="install.sh"
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI
python3 -m venv .venv && source .venv/bin/activate
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu130
pip install -r requirements.txt "huggingface_hub[cli]"
```

## Generate

**From text or a first frame:** Workflow → Browse Templates → Video → **MiniMax H3 T2V** or **I2V**.

**From your own references** — images, a video clip and LoRAs — use this workflow. Drag the file onto the ComfyUI canvas:

<Download href="/blog/minimax-h3/minimax_h3_refs_images_video_loras.json" title="MiniMax H3 — images + video + LoRAs" meta="ComfyUI workflow · built on the official reference-to-video template" />

- **Images** — upload into *Reference image 1 / 2*. Plug more Load Image nodes into the empty `ref_image` slots (up to 9).
- **Video** — upload a short clip into *Reference video*. No video? Select both video nodes and press **Ctrl+B**.
- **LoRAs** — drop files in `models/loras/`, pick one in *Your LoRA 1 / 2*, then **Ctrl+B** to switch it on.
- **PRO 6000** — set *Load Diffusion Model* to `minimax_h3_ref2va_bf16.safetensors`.

Name references by tag in the prompt, in the order they're connected:

```text title="prompt"
Use <Picture 1> as the main character — keep the face and outfit.
Use <Picture 2> for the location and colour palette.
Copy the camera move and pace from <Video 1>.
Shot: she walks toward camera, stops, looks up as the light shifts.
Audio: footsteps, room tone, one soft line of dialogue, no music.
```

<Tip>
Size is set by megapixels in *Resolution Selector*: 0.4 = 864 × 480 (fast), 0.98 = 1344 × 768 (native). Keep reference clips short — every reference rides along each sampling step.
</Tip>
